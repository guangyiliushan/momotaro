# 产品信任面与分发工程

本文承载两组决策的实施细则：**信任与成本的产品面**（D33–D36，2026-09 产品
竞品与信任经济调查）与**更新分发**（D43–D46，2026-09 分发与更新工程调查）。
决策记录见 [Architecture](architecture.md) §22。

一句话：**信任靠离散档位与验证终点呈现，不靠数字与叙事；分发走动态薄层，
迁移永远单事务 + 强制备份。**

## 1. 定位表述（D33）

对外表述：**「本地优先、跨平台、LLM 时代、带 chunk 级引用绑定与信任档的同库
互检科研工作台」**——说「首个组合」，不说「首创」（DEVONthink 25 年先例 +
Omnisearch 187.9 万下载会被内行指出）。差异化护城河是四项的组合：

```text
双向互检（笔记↔论文命中互相附带） × 五元组引用绑定 × 信任档 × 本地优先
```

四项中任何单项都有先例，组合无在位者。目标人群：重度阅读型研究者（人文/
社科/数学），已在 Obsidian+Zotero 双持、被单向管道和云端 AI 困扰的用户。
**付费意愿未验证**——下一份证据必须来自用户访谈或落地页测试，不追加竞品
调查，也不为未验证需求写代码。

叙事纪律：不引用无主数据（52%/95%/85% 三条流传声明均已溯源证伪）；可引用
有 DOI 的行为学研究或可复现的自家数字；「不训练数据」已 commodity 化，
差异化话术锚定**可验证性**（引用绑定 + 确定性校验通过率）。

## 2. 信任三表面（D34）

### 信任级显示

1. **离散档位徽标**，不用数字分数（Dietvorst 不对称惩罚：一次低分即弃用）；
2. 徽标**内联出现在每条证据/每句引用处**（来源呈现形态实质改变核验行为）；
3. proposed 内容显示灰色「待 pin」态而非隐藏（知情判断权）；
4. 显示的目标是让「降级/排除低信任源」这个动作便宜（源 checkbox 模式），
   不是教育用户。

### Provenance 面板

两级漏斗：**hover 出五元组摘要**（文档/位置/信任级/pin 状态），**点击跳原文
并高亮**。面板前置**系统已代为验证的结论**（通过/失败/文档漂移）——用户
很少真的点开引用，验证结论必须主动呈现，不让用户自己从 prompt 推断。引用
是结构化契约：系统生成并校验指向，禁止模型自由发挥引用文本。

### Trace 回放

时间线：query → 检索命中与信任级 → 进入 prompt 的证据 → 模型与参数 →
**验证结果为默认终点**（首屏显示通过/失败/漂移）。每步可展开看当时的原始
对象；回放可回答「pin 决策当时依据的是什么证据」。

三条总原则：透明≠信任（成功标准是改变核验行为）；顺序即干预（证据先于
断言）；引用是结构化契约（真实可点 + 系统校验）。

## 3. 首启价值与 key 配置（D35）

1. **无 key 本地能力是首启信任基座，不是降级态**：首启默认进入本地 index +
   lexical search 可用的工作区，首个动作零成本；AI 功能表述为「未启用」而非
   「不可用」，给出最短解锁路径（免费额度 provider 优先）；empty state 不留
   空（内置示例库/示例检索）；
2. **本地模型形态**：小模型只支撑非对话功能（embedding/OCR 类，百 MB 级），
   或指向免费额度 provider；**不把「装 Ollama+pull 模型」作为默认首启路径**
   （五个非开发者断点 + GPU 静默回退 CPU 暗坑）；内置聊天 LLM（1.6GB+）是
   可选增强不是默认；
3. **key 配置页五要素**：provider 预设列表（免填 Base URL）；粘贴 key +
   「测试连接」（失败给可操作文案）；内嵌申请指引（聊天订阅≠API 账号）；
   指向免费额度 provider；keyring 存储不回显（D28）。

## 4. 成本展示与用量页（D36）

1. **粒度**：per-run 一行小字（`≈¥0.03 · 8.0K in（6.1K cached）+ 1.5K out`），
   悬停展开计价口径；统计页聚合（热力图 + 按模型/provider 下钻）；expand
   search 不逐条展示（单次 ≈¥0.004 是噪音）；lexical search 标注「本地检索，
   无 API 成本」；
2. **unknown 红线四态**：确证免费 = `¥0`/「免费」；已知定价 = `≈¥0.03`（附
   快照日期）；未知定价 = token 照常显示、金额 `¥?`/「未估算」（悬停提示可
   自填单价）；usage 缺失 = 两者均 `unknown`。**绝不把未知渲染成 0**；
3. **BYOK 措辞**：「token 数是事实（API 响应），金额是估算（≈）」视觉分离；
   固定免责「实际计费以你的服务商账单为准」；「Momotaro 本地运行、不经手
   你的 API 请求，不加价、不抽成」明说；禁用「余额/额度快用完」类措辞；
4. **技术细节**：缓存 token 单列（各 provider 折扣差 12 倍，混入普通输入会
   系统性错估）；双币显示；自填单价覆盖（第三方中转场景）；价格快照
   >90 天在统计页提示过期；
5. **成本叙事**：「agent 贵在循环，Momotaro 贵在克制」——单 turn 动作形态
   使重度月成本 ¥5–60，比云端 agent 实测账单低 1–2 个数量级。

## 5. 更新管线（D43）

1. **endpoint 双源**：主源 = 轻量动态层（Serverless 级百行代码），职责三件——
   中国可达性、灰度放量（install-id hash 取模）、紧急停更（204）；备源 =
   GitHub Releases 静态 latest.json（fallback 语义：首个 2XX 即停）；
2. **通道**：stable/beta 两条 endpoint 隔离（版本号不设防）；beta 用
   `x.y.z-beta.N` 单向门，切换 UI 明示；
3. **灰度**：安装时生成稳定 install-id 随 check 请求带 header；服务端
   `hash(install_id) % 100 < stagingPercentage`；1.0 起步 5%。坏版本应急 =
   立即发更高版本号修复版（已升级用户收不回）；
4. **状态机自建**：启动延迟 N 秒查一次 + 24h 节流 + 手动入口；
5. **Windows 唯一安全窗口**：`on_before_exit` 钩子里完成 WAL checkpoint 与
   会话落盘（安装步骤会杀进程）；
6. **密钥纪律**（与 D39 合流）：私钥只在发布 CI 受信 environment + 离线冷备
   双份；丢失 = 全体老用户断更；
7. **明确不做**：delta 差分（包体积不值得自研）、macOS/Linux 静默安装
   （平台必弹框）、「启动即崩自动回退二进制」（无先例，数据防线替代）。

## 6. 签名与分发路径（D44）

1. **macOS**：$99 Apple Developer Program + 公证，1.0 必选（唯一小额年费
   消掉最重摩擦；Tauri 内建 notarytool + staple）；
2. **Windows**：**OV 档**——Certum 开源开发者 OV（€69 起/年，自然人可办）
   或 SignPath Foundation（OSS 免费 HSM 签名）；同一证书签每一版（发布者
   信誉跨版本继承）。理由：目标人群是非开发者研究者，SmartScreen 绕过说明书
   的转化损耗远大于开发者产品。**EV 证书明确不做**（2024 年起无 SmartScreen
   加成，纯溢价）；
3. **Linux**：AppImage + GitHub 直发起步 + GPG 内嵌签名；Flathub 上架后置；
4. **1.0 预算**：macOS $99 + Windows €69 ≈ $200/年量级。

## 7. 崩溃处理与遥测（D45）

1. **零遥测默认**：无启动 ping、无使用统计、无自动崩溃上报；唯一网络行为 =
   更新检查（可关）。纯本地不外发在 GDPR 下不构成「处理」，无需同意界面；
2. **崩溃链路**：panic hook → 本地 JSONL journal（`crash/` 目录，写入时
   home→`~` 脱敏，轮转 20 条）→ doctor 查看与导出。**永不写 minidump**
   （栈内存夹带正在处理的用户内容）；
3. **诊断 bundle**（用户主动导出，先枚举内容再给按钮）：含版本/OS/脱敏
   panic/库聚合计数；排除任何库内容、完整路径、主机名、API key、IP、minidump；
4. 解析层 panic（D37 四件套）写入同一 journal，归因到来源 paper。

## 8. 迁移安全与通道数据隔离（D46）

1. **迁移单事务**：全部 SQL 一个事务，`PRAGMA user_version` 是事务内最后一
   条——中途崩溃自动回滚，不存在半迁移状态；lint 规则：VACUUM 与
   journal_mode 切换禁止出现在迁移事务内；
2. **迁移前强制备份（D32 的第一个强制调用场景）**：备份失败则迁移拒绝开始，
   无跳过选项；产物命名带前后版本号；磁盘预检（原地 VACUUM 需约 2 倍库空间）；
3. **进度 UI**：O(1) DDL 显示阶段名不给时间；O(n) 步骤分批回填自报进度
   （SQLite 无语句级进度回调）；
4. **版本锁文案六要素**：对象点名 → 拒绝理由 → 首选出路（升级+下载按钮）
   → 次选出路（备份位置+打开按钮）→ 不锁应用只锁库 → 旧开新无逃生门按钮
   （Firefox 藏 `-allow-downgrade` 是刻意设计；Momotaro 单库 canonical 风险
   更高）；
5. **崩溃循环防护 = 数据防线组合**：迁移后首启崩 → 二次进安全模式（只读
   视图）+ 「从迁移前备份另存副本」出口 + 服务端 stable 清单回指旧版；
6. **库文件身份**：每个自建库写入 `PRAGMA application_id = 0x4D4D4F54`
   （ASCII `MMOT`）；打开时身份不符即 `ForeignDatabase` 拒绝，"带版本载体却无
   身份"的文件同样拒绝（`NoIdentity`）——凡写过版本载体的构建都写过身份，两者
   出自同一次改动。**拒绝路径零写入**：`Store::refuse_write()` 依次判 身份（`ForeignDatabase`）
   → 版本过新（`SchemaTooNew`）→ 旧载体（`LegacyStore`；**刻意排在第三方对象之前**，
   好让真旧库读到"重建"而不是"这不是我们的库"）→ 无身份却带版本（`NoIdentity`）
   → 第三方对象（`ForeignObjects`），全部通过才允许第一次写入（建表与 WAL 切换
   都算写入）。旧 dev 库（版本号记在 `schema_meta`）报 `LegacyStore`，不迁移、按
   [ADR 0002](adr/source-key-is-scheme-prefixed.md) 重建。
7. **通道数据隔离**：beta 与 stable 分库目录（VS Code Insiders 模式）；首个
   beta 从 stable 复制副本初始化，从此各自演化；schema 不承诺跨通道兼容；
   beta 发布说明必须注明「含 schema 迁移 vN，加入后无法回退 stable」。
