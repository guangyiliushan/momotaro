# Momotaro

A local-first research workbench for serious STEM learners. It connects notes,
papers, and later web sources into a traceable and verifiable desk.

People judge, annotate, and write. The agent retrieves, compares, and proposes
sparks.

> Deterministic first. AI where it matters. Every answer traceable.
> Humans author. Agents assist.
