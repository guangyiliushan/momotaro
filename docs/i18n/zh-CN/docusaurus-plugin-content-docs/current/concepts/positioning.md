# 定位与原则 {/* #what-momotaro-is */}

Momotaro 是一个为认真学习者准备的本地优先科研工作台。它把笔记与论文变成一张可检索、可引用、可验证的书桌：你判断、批注、写作；agent 检索、对照、提议。

> 确定性优先。AI 用在刀刃上。每个答案都可追溯。

## 不是什么 {/* #not */}

- **不是通用科研 agent。** Momotaro 不会替你把任务跑到终点——无人值守的实验、代笔的论文，都没有。
- **不是聊天产品。** 没有产品 Web 后端；工作台就是你机器上的文件与一个本地数据库。
- **不是知识图谱。** 检索是词法的、可解释的；模型没有工具、没有自由循环。
- **不是记忆系统。** agent 产出的东西，自己永远不会变成事实。
- **还不是团队工具。** 0.x 是一人一机：工作区是单用户的；协作是显式的未来话题，而不是偷偷的默认。

## 书桌，不是司机 {/* #desk-not-driver */}

| | 通用科研 agent | Momotaro |
|---|---|---|
| 主角 | agent 把流程跑完 | 人做判断；agent 打下手 |
| 成功标准 | 任务闭环、自动报告 | 证据可追溯、批注沉淀、启发卡收进项目 |
| 默认动作 | 自己搜、自己下、自己写 | 先展示；写入、下载、入库要你点头 |
| 知识 | 模型说了算 | 只有你手写的才是事实；AI 产出永远是待议 |
| 工作单元 | 自由 tool loop | 项目是书桌；一次[运行](../glossary.md#run)是一次可审计的劳动 |

## 三条承诺 {/* #commitments */}

1. **确定性优先。** 检索、分块与引用校验不消耗模型 token。模型只用在真正需要判断的地方——每次[提问运行](../glossary.md#ask)至多一次调用。
2. **人是作者。** 你的笔记与批注才是事实。agent 提议的东西在被收下之前一直处于"待议"；一张[启发卡](../glossary.md#spark)只有经人手才成为来源。
3. **每个答案可追溯。** 答案携带[引用](../glossary.md#citation)，每条引用都能指回当时可校验的确切字节。

## 去向 {/* #direction */}

0.x 是引擎期，全部经由命令行驱动。第一个正式版本是跨平台桌面应用加 CLI；只读为主的移动端伴侣更晚。没有产品 Web 后端——除了你自己选择发布的内容，什么都不离开你的机器。
