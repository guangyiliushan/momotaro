# Momotaro {/* #momotaro */}

本気で学ぶ人のためのローカルファーストな研究ワークベンチです。あなたが判断し、注釈し、書く。エージェントは検索し、照合し、提案します。ここにあるページは安定した振る舞いだけを書きます——今日頼れる概念、判断、ワークフローです。
