# モモタロウとは {/* #what-momotaro-is */}

モモタロウは、本気で学ぶ人のためのローカルファーストな研究ワークベンチです。ノートと論文を、検索でき、引用でき、検証できる机に変えます。あなたが判断し、注釈し、書く。エージェントは検索し、照合し、提案します。

> 決定論を先に。AI は要るところに。すべての答えは追跡可能に。

## そうではないもの {/* #not */}

- **汎用の研究エージェントではありません。** モモタロウはタスクを最後まで代行しません——無人実験も、代筆された論文もありません。
- **チャット製品ではありません。** 製品の Web バックエンドはありません。作業台はあなたのマシン上のファイルと、1 つのローカルデータベースです。
- **知識グラフではありません。** 検索は語彙ベースで説明可能。モデルにツールはなく、自由なループもありません。
- **記憶システムではありません。** エージェントの産物が、それだけで事実になることはありません。
- **まだチームの道具ではありません。** 0.x は 1 人 1 台：ワークスペースは単一ユーザーで、共同作業は暗黙の既定ではなく、明示的な未来の話題です。

## 机であり、運転手ではない {/* #desk-not-driver */}

| | 汎用研究エージェント | モモタロウ |
|---|---|---|
| 主役 | エージェントが工程を走り切る | 人が判断し、エージェントが手伝う |
| 成功の基準 | タスクが閉じ、レポートが出る | 証拠が追跡でき、注釈が積もり、スパークがプロジェクトに収まる |
| 既定の動作 | 自分で探し、落とし、書く | まず見せる。書き込み・ダウンロード・取り込みはあなたの確認が要る |
| 知識 | モデルの言い分 | 事実はあなたの手書きだけ。AI の産物は提案のまま |
| 作業の単位 | 自由なツールループ | プロジェクトは机。[ラン](../glossary.md#run)は監査可能な労働 1 回分 |

## 3 つの約束 {/* #commitments */}

1. **決定論を先に。** 検索・チャンク分割・引用検証はモデルのトークンを消費しません。モデルは本当に判断が要るところだけ——1 回の[アスク](../glossary.md#ask)につき多くとも 1 ターンです。
2. **人が著者。** 事実になるのはあなたのノートと注釈だけです。エージェントの提案は人がピン留めするまで「提案」のまま；[スパーク](../glossary.md#spark)がソースになるのは人の操作によってのみです。
3. **すべての答えが追跡可能。** 答えは[引用](../glossary.md#citation)を伴い、各引用はその時点で検証可能だった正確なバイトを指します。

## これから {/* #direction */}

0.x はエンジン期で、コマンドラインから駆動します。最初の正式リリースはクロスプラットフォームのデスクトップアプリと CLI。読み取り中心のモバイル相棒はそのあとです。製品の Web バックエンドはありません——あなたが公開を選んだもの以外、マシンから何も出ていきません。
