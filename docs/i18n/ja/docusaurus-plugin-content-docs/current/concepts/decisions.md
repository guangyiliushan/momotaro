# 設計判断 {/* #decisions */}

ここに集めるのは、使う人が体で感じられる選択——製品の形であり、内部実装ではありません。各項目は判断・理由・払った代償を示します。各判断の実装は工学であり、工学は変わります。ここに書かれたことが、あなたが頼れるものです。

## 決定論を先に {/* #deterministic-first */}

**判断。** 検索・チャンク分割・引用検証はモデルを一切関与させません。モデルは本当に判断が必要な場所でだけ呼ばれます。

**理由。** 再現でき、オフラインで動き、コストが正直です。検索は何も消費せず、同じクエリはどのマシンでも同じ結果を返します。

**代償。** 0.x では意味の言い換えをしません——あなたの言葉と文書の言葉が重ならなければ、語彙検索は取り逃します。逃げ道（埋め込み）は「念のため」ではなく、証拠が求める日まで意図的に先送りされています。

## すべての答えが追跡可能 {/* #traceable */}

**判断。** 答えは引用を伴い、すべての引用はあなたが目にする前に記録されたリビジョンと照合され、失敗は失敗として示されます。

**理由。** 信頼できるシステムは「信じてください」と言えません。バイトは確認できますが、モデルの記憶は確認できません。仕組みは[検索と引用](retrieval-and-citations.md)に。

**代償。** 検証に失敗した主張を滑らかにしない分、読み味の落ちる答えもあります——証拠が切れたら、モデルが自信満々でも、システムは黙ります。

## 人が著者 {/* #people-author */}

**判断。** 事実になるのは人の書き物だけ。エージェントの産物は人がピン留めするまで提案のまま。ノートに自動で書き込まれることは、決してありません。

**理由。** 机はあなたのもの——証拠も判断も著者性も、人の手に残ります。[スパーク](../glossary.md#spark)がライブラリの一部になるのは、人の操作によってだけです。

**代償。** 便利さの犠牲——「勝手に整理しておく」類の自動化は、設計上存在しません。

## ローカルファースト、テレメトリゼロ {/* #local-first */}

**判断。** 作業台はあなたのマシン上のファイルと、1 つのローカルデータベース。始めるのにアカウントは要らず、テレメトリは決してありません。

**理由。** 読み書きの軌跡は研究データであり、研究データは研究者のものです。あなたのライブラリについて、集めも数えも送信もしません。

**代償。** 0.x にクラウド同期もクロスデバイスもありません——ワークスペースの引っ越しはディレクトリのコピーです。検証可能性とプライバシーのための、意図した取引です。

## ライブラリは 1 つ {/* #one-library */}

**判断。** ノートと論文は 1 つの索引と 1 つの結果リストを共有します。

**理由。** 2 種類の材料は並んでいる時に最も役立ちます——論文のヒットと、それに反論するノートが、1 つの順位付きビューに。別々の検索に分ければ、ワークベンチが存在する理由である「材料どうしの照らし合い」を、ちょうど隠してしまいます。

**代償。** 順位付けで追い払うノイズが増えます。オリジン加重がその補償です（[検索と引用](retrieval-and-citations.md)）。

## アーカイブは削除ではない {/* #archive-not-deletion */}

**判断。** 役目を終えた材料はアーカイブへ。破壊は別の、明示的な操作です。移行は触る前に必ずバックアップを取ります。

**理由。** 研究データは、後になって効いてくる歴史を蓄えます——古い注釈、置き換えられたリビジョン。不可逆が敵です。あなたの仕事を静かに失えるシステムに、その仕事を預けることはできません。

**代償。** あなたが減らすと決めるまでディスク使用量は増え続け、整理は人間の判断のまま——バックグラウンドの「掃除」にはなりません。

## Web バックエンドはない {/* #no-web-backend */}

**判断。** 製品はデスクトップとコマンドライン。サーバー側の製品も、会社が持つライブラリの写しもありません。

**理由。** 作業台は研究者と一緒に住みます——ファイルはもともとあなたのマシンにあり、バックエンドは真実をそこから遠ざけるだけです。

**代償。** 「どのブラウザからでも開ける」話はなく、共有は自分でファイルを公開することを意味します。どちらも未来の、明示的に議論すべき話題であり、黙って有効になる既定値ではありません。
