# 核函数 Kernel Functions

核函数是定义在样本对上的对称函数 k(x, y)，它等于某个特征映射 φ 的内积：
k(x, y) = ⟨φ(x), φ(y)⟩。核技巧（kernel trick）只用 k 的取值计算内积，
从不显式构造 φ，把高维特征空间的运算折算到低维完成。

## 常见核

- 线性核：k(x, y) = ⟨x, y⟩；
- 多项式核：k(x, y) = (⟨x, y⟩ + c)^d，d 是次数；
- RBF（高斯）核：k(x, y) = exp(−γ ‖x − y‖²)；
- Sigmoid 核：k(x, y) = tanh(α ⟨x, y⟩ + c)。

RBF 核的特征空间是无限维的，且具有平移不变性。
